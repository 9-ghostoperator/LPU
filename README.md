COLLEGE PROPERTY MANAGEMENT PORTAL
==================================

ABOUT THIS PROJECT
This is a simple first-year college project made with HTML, CSS and basic JavaScript.
It follows the Property Management Portal requirements from the provided project brief.

REQUIREMENTS INCLUDED
1. User registration and login (demo only).
2. Role-based access for Admin, Staff and Student.
3. Dashboard with property and request totals.
4. CRUD operations for property records (Admin can add, view, edit and delete).
5. Search and filter for property records.
6. Request workflow for Maintenance, Booking and Allocation requests.
7. Request status tracking: Pending, In Progress, Resolved or Rejected.
8. Form validation and confirmation messages.
9. Basic reports that count properties and requests by status.
10. Responsive UI for desktop and mobile screens.
11. LPU logo on the login page and main portal header.

HOW TO RUN
1. Extract the ZIP file.
2. Keep index.html, style.css and script.js in the same folder.
3. Double-click index.html to open it in a browser.
4. Use one of the demo accounts below, or register a new Student account.

ROLE RULES
Admin: can view properties and add, edit or delete property records; can view and update all requests.
Staff: can view properties and view/update all requests.
Student: can view/search properties, submit requests and track their own requests.
New registrations are given Student access.

FILES
index.html - page structure and forms
style.css  - simple colours, spacing, tables and responsive layout
script.js  - login/register demo, role checks, properties, requests, search and reports

LPU LOGO
The official LPU logo is loaded from the university website, so an internet connection is needed
to show the full logo. If it cannot load, a simple LPU text badge appears instead.

IMPORTANT LIMITATION
This is a front-end demonstration, not a secure production system. It stores its records in
browser localStorage. The demo passwords are not protected and there is no server or shared
database. Do not use real passwords or sensitive information. A real system would need a
backend, database and secure authentication.

VIVA TIP
Be ready to explain HTML forms and tables, CSS selectors and media queries, JavaScript arrays,
functions, events, if statements, and localStorage. You should test each feature yourself and
understand the code before presenting it.
